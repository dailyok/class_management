# 🏫 초등 학급 경영 & 게이미피케이션 웹 앱 (`class_management`)

초등학교 6학년 학급을 위한 학급 경제(화폐) 및 게이미피케이션(경험치, 레벨) 기반 학급 관리 웹 애플리케이션입니다.

## ✨ 주요 기능

### 1. 분리된 모드 및 간이 인증
- **교사 모드**: 관리자 PIN(`1234`)을 입력하여 학급 전체 통합 관리 대시보드 진입
- **학생 모드**: 1~23번 학생 번호 선택 및 4자리 개인 PIN(`0001`~`0023`) 입력으로 본인 서랍 진입

### 2. 교사용 대시보드
- **통계 요약**: 총 학생 수(23명), 총 유통 화폐량, 1인 평균 잔액, 1인 1역 완수율(%), 오늘 기분 체크율(%) 실시간 집계
- **학생 & 화폐 관리**: 개별 및 일괄 코인 지급/차감
- **1인 1역 현황 및 배정**: 학생별 역할 조회, 수정 및 오늘 수행 여부 체크
- **학급 감정 기상도**: 6가지 감정 분포 및 학생들의 한 줄 일기 모니터링
- **학급 상점 관리**: 상점 쿠폰/물품 등록, 수정 및 재고 관리
- **거래 장부**: 전체 화폐 지급 및 사용 내역 실시간 로그 조회
- **데이터 백업 & 복원**: JSON 내보내기/가져오기 및 초기화 지원

### 3. 학생용 대시보드
- **프로필**: 잔액(코인), 레벨 및 칭호, 다음 레벨까지의 경험치(EXP) 게이지
- **오늘의 기분 체크**: 6가지 감정 이모지와 한 줄 메모 작성
- **오늘의 할 일 (1인 1역)**: 배정된 임무 확인 및 완료 체크
- **학급 상점**: 모은 코인으로 원하는 보상/쿠폰 구매
- **내 보관함**: 구매한 쿠폰 확인 및 담임선생님 확인 후 '사용하기'
- **내 화폐 기록**: 개인별 코인 획득 및 차감 내역 확인

## 🛠️ 기술 스택
- **Frontend**: HTML5, Vanilla CSS, Vanilla JavaScript (ES Modules)
- **Tooling**: Vite
- **Storage**: 브라우저 LocalStorage 기반 오프라인/학교 환경 최적화
- **Effects**: 순수 HTML5 Canvas Confetti (외부 라이브러리/CDN 종속 없음)

## 🚀 시작하기

### 1. 의존성 설치
```bash
npm install
```

### 2. 개발 서버 실행
```bash
npm run dev
```

### 3. 프로덕션 빌드
```bash
npm run build
```
